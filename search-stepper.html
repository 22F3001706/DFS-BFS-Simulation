    MoveGen behaviour
    Terms used on this page
    MoveGen(N)
    Returns the neighbours of N as a list. The order of that list is up to the implementation, which is why exam questions say it is unknown.
    OPEN
    Nodes found but not yet visited. The algorithm takes its next node from here. DFS treats OPEN as a stack, so the newest node comes out first. BFS treats it as a queue, so the oldest comes out first.
    CLOSED
    Nodes already visited. Checking it before adding a node to OPEN stops the search from going back to the same node.
    visit(N)
    The moment a node is taken off OPEN and processed. The visit order is the sequence of these moments.
    expand
    Call MoveGen on the visited node and add its neighbours to OPEN.
